🏠 ArchiGen - House Architecture Design System
📖 Overview
ArchiGen is a Java-based House Architecture Design application developed using Eclipse IDE. The project provides an interactive platform for designing and visualizing house layouts through a user-friendly interface. It demonstrates Object-Oriented Programming (OOP) principles, software design concepts, and application development skills while simplifying architectural planning and layout creation.

✨ Features
🏠 House layout design and visualization
📐 Interactive architectural planning
🖥️ User-friendly graphical interface
🏗️ Structured and modular design system
⚡ Efficient project management
🔄 Object-Oriented Programming implementation
📋 Organized project workflow
