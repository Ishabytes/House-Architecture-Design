# 🏠 ArchiGen – House Architecture Design System

## 📖 Overview

**ArchiGen** is a Java-based House Architecture Design application developed using **Eclipse IDE**. It provides an interactive platform for designing and visualizing house layouts through a user-friendly graphical interface.

The project demonstrates **Object-Oriented Programming (OOP)** principles, software design concepts, GUI development, and problem-solving skills while providing a simple environment for house layout planning.

## ✨ Features

* 🏠 House layout design and visualization
* 📐 Interactive architectural planning
* 🖥️ User-friendly graphical interface
* 🏗️ Structured and modular design
* 🔄 Implementation of Object-Oriented Programming concepts
* 📋 Organized project workflow
* ⚡ Simple and interactive design experience

## 🛠️ Technologies Used

* **Java**
* **Eclipse IDE**
* **Java Swing / AWT**
* **Object-Oriented Programming (OOP)**

## 🚀 How to Run

1. Download or clone this repository.
2. Open **Eclipse IDE**.
3. Import the project into your Eclipse workspace.
4. Make sure the required Java version is configured.
5. Locate the main Java file.
6. Run the application.
7. Start designing and visualizing house layouts.
